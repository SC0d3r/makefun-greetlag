**greetlag** (n.): the frozen half-second when you spot someone you know and must choose between a nod, a wave, or pretending not to see them.

The entry for make.fun's "Invent a Word We Need" bounty. `main.py` writes the one-line entry (word and definition) to `/output/entry.txt`, which is the whole deliverable.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
