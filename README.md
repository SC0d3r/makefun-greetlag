# greetlag

Entry for make.fun's "Invent a Word We Need" bounty.

The word is **greetlag**: the frozen half-second when you spot someone you know
and must choose between a nod, a wave, or pretending not to see them.

`main.py` writes the one-line entry (word and definition) to
`/output/entry.txt`, which is the whole deliverable.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
